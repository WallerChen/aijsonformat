Common use cases

  • Clean titles, identifiers and documentation snippets.

FAQ

What cases are generated?

The tool outputs camelCase, PascalCase, snake_case, kebab-case, uppercase and lowercase.

Is this useful for code?

Yes. It helps convert labels, keys and file names into code-friendly forms.

Does it support punctuation?

Punctuation is treated as a word separator.
