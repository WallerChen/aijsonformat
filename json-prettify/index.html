FAQ

What is prettified JSON?

Prettified JSON is JSON printed with line breaks and indentation.

Why prettify JSON?

It makes nested data easier to inspect and debug.

Can I prettify JSON from logs?

Yes, as long as the JSON portion is valid or repaired first.
